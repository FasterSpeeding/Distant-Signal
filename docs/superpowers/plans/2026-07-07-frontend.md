# Frontend (Next.js + Mantine) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Next.js + TypeScript + Mantine v9 frontend at `frontend/`
that consumes the existing read API and presents a TfL-style line status
dashboard, plus line detail, station lookup, and history pages.

**Architecture:** Server Components fetch the API server-side per page
(no client-side data library needed). The `api` crate gets a permissive
CORS layer so the browser *could* call it directly in the future, even
though v1 doesn't need to. Four routes, a small typed API client layer,
a severity→color mapping table, and three shared display components.

**Tech Stack:** Next.js 16 (App Router), React 19, TypeScript, Mantine v9
(`@mantine/core`, `@mantine/hooks`, `@mantine/dates`), Vitest + React
Testing Library for tests. Backend: `tower-http`'s `CorsLayer` (dependency
already present, unused until this plan).

## Global Constraints

- **CORS is permissive** (`Any` origin, GET only) on the `api` crate — no
  configurable allowlist. All four read endpoints are already
  unauthenticated, read-only GETs of public data; there is no
  credential/cookie exposure to protect against.
- **No admin/authoring features, no station name→CRS lookup, no
  client-side polling/WebSockets, no E2E test tooling** — all explicitly
  out of scope per the design doc.
- **Severity colors cover all 17 `Severity` values** (0-14, 20, 21) from
  the table in the design doc — not a partial map with a silent fallback
  for known values (an *unrecognized* numeric value falls back to a
  defined default, but every real `Severity` value must hit a real
  table entry).
- **TypeScript types in `lib/types.ts` are hand-written to match
  `render.rs`'s actual JSON output** — camelCase field names, `disruption`
  optional, no auto-generation.
- **Dashboard and line-detail pages revalidate every 30s** (`next:
  { revalidate: 30 }`); station lookup and history are on-demand,
  no auto-refresh.
- **`params`/`searchParams` in Next.js 16 App Router page components are
  `Promise`s and must be `await`ed** — do not write them as plain
  synchronous props (this project's Next.js version is 16.2.10, confirmed
  during planning; the promise-based API has been current since 15.0.0-RC).

**Endpoints** (all on `crates/api`, unauthenticated, unprefixed):
- `GET /Line/Mode/{mode}/Status` — 400 if `mode != "national-rail"`.
- `GET /Line/{ids}/Status?detail=true` — `{ids}` comma-separated; 404 only
  if none match.
- `GET /StopPoint/{crs}/Disruption` — returns `[]` if nothing disrupted.
- `GET /Line/{id}/Status/{from}/to/{to}` — `{from}`/`{to}` are RFC3339
  timestamps in the URL path.

```rust
use tower_http::cors::{Any, CorsLayer};
use tower_http::trace::TraceLayer;

use crate::app::{AppState, Router};

pub mod app;
pub mod auth;
pub mod data;
pub mod render;
pub mod routes;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    dotenv::dotenv().ok();

    let app = AppState::init().await?;

    // Permissive by design: every route this layer covers is already an
    // unauthenticated, read-only GET of public data (mirroring TfL's own
    // publicly-CORS-enabled API) — there is no credential/cookie exposure
    // to restrict, so a configurable origin allowlist would add config
    // surface for no real benefit.
    let cors = CorsLayer::new()
        .allow_methods([axum::http::Method::GET])
        .allow_origin(Any);

    let router = Router::new()
        .merge(routes::line_status::router())
        .nest("/public", routes::public_router())
        .nest("/private", routes::private_router(app.clone()))
        .layer(cors)
        .layer(TraceLayer::new_for_http())
        .with_state(app.clone());

    tracing_subscriber::fmt()
        .with_env_filter(tracing_subscriber::EnvFilter::from_default_env())
        .init();

    sqlx::migrate!().run(&app.database).await?;

    let listener = tokio::net::TcpListener::bind(&app.config.bind_url).await?;
    axum::serve(listener, router).await?;
    Ok(())
}
```

```ts
import type { LineStatusReport, LineStatusHistoryEntry } from './types';

function baseUrl(): string {
  const url = process.env.API_BASE_URL;
  if (!url) {
    throw new Error('API_BASE_URL environment variable is not set');
  }
  return url;
}

async function fetchJson<T>(url: string, init: RequestInit): Promise<T> {
  const response = await fetch(url, init);
  if (!response.ok) {
    throw new Error(`API request to ${url} failed: ${response.status} ${response.statusText}`);
  }
  return response.json() as Promise<T>;
}

export async function getLineStatusForMode(mode: string): Promise<LineStatusReport[]> {
  return fetchJson<LineStatusReport[]>(`${baseUrl()}/Line/Mode/${mode}/Status`, {
    next: { revalidate: 30 },
  });
}

export async function getLineStatus(ids: string[], detail: boolean): Promise<LineStatusReport[]> {
  const idsParam = ids.join(',');
  const query = detail ? '?detail=true' : '';
  return fetchJson<LineStatusReport[]>(`${baseUrl()}/Line/${idsParam}/Status${query}`, {
    next: { revalidate: 30 },
  });
}

export async function getStopPointDisruption(crs: string): Promise<LineStatusReport[]> {
  return fetchJson<LineStatusReport[]>(`${baseUrl()}/StopPoint/${crs}/Disruption`, {
    cache: 'no-store',
  });
}

export async function getLineStatusHistory(
  id: string,
  from: string,
  to: string,
): Promise<LineStatusHistoryEntry[]> {
  return fetchJson<LineStatusHistoryEntry[]>(
    `${baseUrl()}/Line/${id}/Status/${from}/to/${to}`,
    { cache: 'no-store' },
  );
}
```

- [ ] **Step 11: Write `components/LineStatusCard.tsx`**

A line's card shows the worst (lowest-severity-number) status's badge and
reason — matching `common::LineStatusReport::worst_severity`'s "lower is

```tsx
import { Card, Group, Text, Stack } from '@mantine/core';
import Link from 'next/link';
import { StatusBadge } from './StatusBadge';
import type { LineStatusReport } from '@/lib/types';

function worstStatus(report: LineStatusReport) {
  if (report.lineStatuses.length === 0) {
    return { statusSeverity: 10, reason: 'Good Service' };
  }
  return report.lineStatuses.reduce((worst, current) =>
    current.statusSeverity < worst.statusSeverity ? current : worst,
  );
}

export function LineStatusCard({ report }: { report: LineStatusReport }) {
  const worst = worstStatus(report);
  return (
    <Card withBorder shadow="sm" padding="lg" component={Link} href={`/lines/${report.id}`}>
      <Stack gap="xs">
        <Group justify="space-between">
          <Text fw={600}>{report.name}</Text>
          <StatusBadge severity={worst.statusSeverity} />
        </Group>
        <Text size="sm" c="dimmed">
          {worst.reason}
        </Text>
      </Stack>
    </Card>
  );
}
```

```tsx
export function HistoryRangePicker({ lineId }: { lineId: string }) {
```

- [ ] **Step 1: Write `frontend/Dockerfile`**

Multi-stage: install deps, build, run with `next start`.

```dockerfile
# Multi-stage build for the `frontend` service.
#
# Build from the repo root so relative paths work the same way as every
# other service's Dockerfile in this project:
#   docker build -f frontend/Dockerfile -t frontend .
FROM node:22-bookworm-slim AS builder

WORKDIR /app
COPY frontend/package.json frontend/package-lock.json ./
RUN npm ci
COPY frontend/ .
# API_BASE_URL is read at request time in Server Components (not baked
# into the build), so no build-time env var is needed here.
RUN npm run build

FROM node:22-bookworm-slim

RUN useradd --system --no-create-home --shell /usr/sbin/nologin frontend

WORKDIR /app
COPY --from=builder --chown=frontend:frontend /app/.next ./.next
COPY --from=builder --chown=frontend:frontend /app/node_modules ./node_modules
COPY --from=builder --chown=frontend:frontend /app/package.json ./package.json
# No `public/` directory: this plan adds no static assets (no favicon,
# no images). Next.js's `public/` dir is optional — omitting this COPY
# is correct, not a shortcut. If a later change adds static assets under
# `frontend/public/`, add `COPY --from=builder --chown=frontend:frontend
# /app/public ./public` back in at that point.

USER frontend

EXPOSE 3000
ENTRYPOINT ["npm", "run", "start"]
```
